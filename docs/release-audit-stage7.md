# Релизный аудит Kenai VPN Client — этап 7

> Исторический снимок этапа 7. Состояние Windows-службы и production-активации
> обновлено документами этапов 8 и 9; финальный MVP-аудит будет выполнен заново.

Дата проверки: 2026-09-05. Целевая платформа текущего этапа: Windows.

## Вердикт

**BLOCKED — приложение не готово к публикации.** Каркас, mock-функции и
пользовательские экраны проходят quality gate, но production-релиз запрещён до
закрытия перечисленных ниже блокеров. Сборка release в рамках аудита является
только технической проверкой и не публикуется.

## Результаты

| Проверка | Статус | Подтверждение / следующий шаг |
|---|---|---|
| Отсутствие секретов | PASS для репозитория и diagnostics | Secret scan, redaction-тесты JSONL/UI/ZIP. Повторить для будущих бинарных VPN-профилей. |
| Очистка при выходе | PASS для текущего mock/OS storage | Тест удаляет сессию, ключ и VPN-реквизиты, сохраняя несекретные настройки. Повторить с реальной службой. |
| Безопасные временные файлы | PARTIAL | Диагностический ZIP пишется напрямую в Downloads и не создаёт временный файл. Политика ACL/удаления установщика и обновлений отсутствует до появления этих компонентов. |
| Подпись обновлений | BLOCKED | Production `UpdateProvider` отсутствует; автообновление отключено. Нужны подписанный manifest, закреплённый публичный ключ, hash/signature verification и защита от downgrade. |
| Потеря сети | PASS для state machine, BLOCKED для production | Mock-тесты покрывают `NO_NETWORK` и восстановление. Нужны интеграционные тесты реального адаптера и службы. |
| Восстановление после сна | BLOCKED | Настройка capability-aware и отключена. Нужен реальный Windows power-event adapter и leak test. |
| Конфликтующие подключения | PASS для state machine, BLOCKED для production | Core запрещает параллельные connect/disconnect. Служба должна обеспечить единственный системный tunnel и идемпотентность IPC. |
| Установщик | BLOCKED | Подписанный MSI/MSIX/installer не создан. Нужны install/repair/uninstall, least privilege, service ACL и rollback tests. |
| Обновление и откат | BLOCKED | Update pipeline отсутствует. Нужны атомарная установка, проверка подписи до замены, health check и безопасный rollback. |
| Полный quality gate | PASS для текущего mock-каркаса | Format, analyze, Dart/Flutter tests, release build, Rust fmt/clippy/tests и boundary checks. Это не отменяет production-блокеры. |

## Дополнительные обязательные блокеры

- Реальные WireGuard, AmneziaWG и Xray-адаптеры и минимальная Windows-служба не
  реализованы.
- Production API и платёжный backend не подключены по решению владельца.
- Серверная документация не задаёт публичные URL поддержки и политики
  конфиденциальности.
- Нет production endpoint/методики теста скорости. Release-клиент не показывает
  mock-результаты.
- До публикации нужна ротация журналов с ограничением объёма и утверждённым
  сроком хранения.
- Нужны подпись приложения и установщика, SBOM, проверка зависимостей и процедура
  отзыва скомпрометированного update-ключа.

## Условия снятия блокировки

1. Отдельно реализовать и протестировать Windows-службу и каждый VPN-движок.
2. Подключить типизированный production API без изменения TLS verification.
3. Создать и подписать установщик.
4. Реализовать подписанные обновления и rollback; отрицательные тесты должны
   отклонять повреждённый, неподписанный и более старый пакет.
5. Провести leak/DNS/route/sleep/network-change тесты на чистой Windows VM.
6. Предоставить юридически утверждённую privacy policy и контакт поддержки.
7. Повторить весь quality gate на подписанных артефактах.
