# Threat model VPN-движков и системной интеграции

## Область

Модель применяется до добавления WireGuard, AmneziaWG 2.0 и Xray. Текущий
этап содержит только mock-адаптеры и не устанавливает драйверы, маршруты, DNS
или WFP-фильтры.

## Активы

- ключ активации и клиентская сессия;
- приватные ключи WireGuard/AmneziaWG, VLESS UUID и REALITY-параметры;
- целостность маршрутов, DNS и kill switch;
- право управлять туннелем;
- подписанные binaries, драйверы и обновления;
- диагностические данные без секретов.

## Границы доверия

```text
непривилегированный Flutter GUI
        |
        | локальный типизированный IPC (недоверенный ввод)
        v
минимальная Windows-служба
        |
        +-- engine adapters / подписанные binaries
        +-- Windows routes, DNS, WFP, driver APIs
```

GUI и любой локальный процесс пользователя считаются потенциально
скомпрометированными. Служба не доверяет идентификаторам, состоянию подписки,
путям или параметрам, полученным от GUI, без собственной проверки.

## Угрозы и обязательные меры

| Угроза | Мера |
| --- | --- |
| Подмена клиента IPC | Локальный named pipe, явный DACL, запрет remote clients, проверка PID/token/session и версии контракта |
| Confused deputy | Только allowlist операций; никаких shell-команд, произвольных путей, URL или имён служб из запроса |
| Повтор/гонка команд | Уникальный operation ID, один сериализованный lifecycle, идемпотентность disconnect, отклонение конфликтов |
| Подмена профиля | GUI передаёт непрозрачный profile handle; служба проверяет владельца, сервер, протокол и подписку |
| Утечка секретов | OS secure storage, минимальное время расшифровки, очистка буферов, redaction до логирования/IPC ошибок |
| Подмена engine binary/driver | Закреплённая версия и hash, проверка Authenticode/издателя, защищённый каталог установки |
| DLL/path hijacking | Абсолютные service-owned пути, безопасный DLL search mode, отсутствие writable-by-user каталогов |
| TOCTOU временных конфигураций | Service-owned каталог, user-write запрещён, атомарная запись/rename, валидация перед применением |
| IPv4/IPv6/DNS leak | Kill switch включается до маршрута; отдельные leak-тесты IPv4, IPv6, DNS и failure rollback |
| Routing loop | Исключение только проверенного VPN endpoint; запрет произвольных bypass-маршрутов |
| Зависший kill switch | Персистентное service-owned состояние, recovery при старте, транзакционные WFP-операции и аварийный безопасный rollback |
| Сон/смена сети | Явные события ОС, debounce, сериализованное reconnect, повторная проверка DNS/routes/WFP |
| Crash/reboot | Reconciliation фактического состояния ОС со state machine до ответа `CONNECTED` |
| Поддельный `CONNECTED` | Источник истины — служба и проверка трафика/интерфейса; GUI не подтверждает состояние локально |
| Компрометация обновления | Подпись манифеста и пакета, anti-rollback, атомарная установка и проверенный откат |

## Не покрывается одной службой

Компрометация LocalSystem или ядра находится вне защиты клиента. Меры снижения:
минимальная поверхность службы, отсутствие сетевого listener, строгая цепочка
поставки, code review каждого адаптера и отказ от хранения лишних секретов.

## Обязательный gate перед реальным движком

Каждый протокол проходит отдельный этап: review лицензии и поставки, проверка
подписи, негативные IPC-тесты, тесты crash/reboot/sleep/network change,
IPv4/IPv6/DNS leak-тесты, uninstall/rollback и подтверждение, что GUI работает
без административных прав.
