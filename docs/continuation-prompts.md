# Внутренняя последовательность до минимально рабочего MVP

MVP — устанавливаемое Windows-приложение, в котором пользователь активирует
аккаунт 12-значным ключом и действительно подключается к текущему серверу
«Армения» через WireGuard, AmneziaWG 2.0 или VLESS + REALITY. Платежи,
автообновление, speed test, kill switch и многосерверный API не входят в этот
MVP и не должны изображаться работающими в release.

## Промпт 9 — production-активация

Подключить существующий `POST /api/v1/activate` через HTTPS без отключения TLS,
с таймаутами, ограничением ответа и строгой схемой. Безопасно хранить ключ и
профили трёх протоколов. Использовать compile-time API URL; при отсутствии URL
release закрывается безопасной ошибкой. Удалить mock API/VPN из release
composition root, сохранить mocks для development и тестов. Сервер не изменять.

## Промпт 10 — provisioning профиля в Windows-службу

Расширить IPC типизированной операцией импорта WireGuard-профиля. Разбирать
конфигурацию в непривилегированном адаптере, передавать только ограниченные поля,
проверять адреса, ключи, endpoint и маршруты. Служба сохраняет профиль через
DPAPI/service-owned ACL и возвращает непрозрачный handle. Реализовать удаление
при выходе без логирования секретов.

## Промпт 11 — реальный WireGuard for Windows

Подключить закреплённую официальную embeddable WireGuard реализацию, проверить
происхождение, hash, подпись и лицензию. Реализовать connect/disconnect/status,
DNS, routes, handshake, traffic counters, cleanup и crash recovery. Не включать
kill switch, пока он не проверен отдельными leak-тестами.

## Промпт 12 — GUI, IPC и рабочий сценарий

Заменить release fallback на Windows IPC engine. Связать активацию, профиль,
сервер «Армения» и реальные состояния. Реализовать безопасный выход, ошибки,
перезапуск GUI и отсутствие параллельных операций. Скрыть функции вне MVP.

## Промпт 13 — реальный AmneziaWG 2.0

Подключить AmneziaWG 2.0 как отдельный закреплённый движок. Проверить
происхождение, лицензию, подписи и хэши бинарных компонентов; расширить
типизированный API профиля только параметрами AWG 2.0. Реализовать независимые
connect/disconnect/status, DNS, routes, счётчики, cleanup и crash recovery. Не
выдавать обычный WireGuard за AmneziaWG.

## Промпт 14 — реальный VLESS + REALITY/Xray

Закрепить официальный совместимый Xray-core и добавить VLESS + REALITY как
отдельный адаптер и отдельный профиль IPC. Зафиксировать лицензию, хэш,
безопасный жизненный цикл процесса и минимальные права. GUI не передаёт
произвольные аргументы или пути. Проверить маршрутизацию, DNS, остановку и crash
recovery; UUID, REALITY-параметры и конфигурация не попадают в логи.

## Промпт 15 — установочный EXE со всеми тремя протоколами

Собрать GUI, службу, WireGuard, AmneziaWG и Xray payload в
`KenaiVPN-Setup.exe`. Настроить service SID, ACL, install/repair/uninstall и
очистку. UAC используется только установщиком. Подпись выполняется только при
наличии владельческого сертификата.

## Промпт 16 — end-to-end MVP gate

На чистой Windows VM проверить установку, HTTPS-активацию тестовым 12-значным
ключом и реальные подключения каждым из трёх протоколов: handshake/health,
внешний IP, DNS, disconnect, переключение протокола, перезапуск, неверный ключ и
uninstall. Не использовать production-пользователей и не публиковать артефакт
без отдельного разрешения.
