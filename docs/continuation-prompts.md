# Внутренняя последовательность до WireGuard-first MVP

MVP — устанавливаемое Windows-приложение, в котором пользователь активирует
аккаунт 12-значным ключом и подключается к текущему серверу «Армения» через
WireGuard. AmneziaWG, Xray, платежи, обновления, speed test и многосерверный API
не входят в первый MVP. Они не должны изображаться работающими в release.

## Промпт 9 — production-активация

Подключить существующий `POST /api/v1/activate` через HTTPS без отключения TLS,
с таймаутами, ограничением ответа и строгой схемой. Безопасно хранить ключ и
только WireGuard-профиль. Использовать compile-time API URL; при отсутствии URL
release закрывается безопасной ошибкой. Удалить mock API/VPN из release
composition root, сохранить mocks для development и тестов. Сервер не изменять.

## Промпт 10 — provisioning профиля в Windows-службу

Расширить IPC типизированной операцией импорта WireGuard-профиля. Разбирать
конфигурацию в непривилегированном адаптере, передавать только ограниченные поля,
проверять адреса, ключи, endpoint и маршруты. Служба сохраняет профиль через
DPAPI/service-owned ACL и возвращает непрозрачный handle. Реализовать удаление
при выходе без логирования секретов.

## Промпт 11 — реальный WireGuard for Windows

Подключить закреплённую официальную embeddable WireGuard реализацию, проверить
происхождение, hash, подпись и лицензию. Реализовать connect/disconnect/status,
DNS, routes, handshake, traffic counters, cleanup и crash recovery. Не включать
kill switch, пока он не проверен отдельными leak-тестами.

## Промпт 12 — GUI, IPC и рабочий сценарий

Заменить release fallback на Windows IPC engine. Связать активацию, профиль,
сервер «Армения» и реальные состояния. Реализовать безопасный выход, ошибки,
перезапуск GUI и отсутствие параллельных операций. Скрыть функции вне MVP.

## Промпт 13 — установочный EXE

Собрать GUI, службу и WireGuard payload в `KenaiVPN-Setup.exe`. Настроить service
SID, ACL, install/repair/uninstall и очистку. UAC используется только
установщиком. Подпись выполняется только при наличии владельческого сертификата.

## Промпт 14 — end-to-end MVP gate

На чистой Windows VM проверить установку, HTTPS-активацию тестовым ключом,
WireGuard handshake, внешний IP, DNS, disconnect, перезапуск, неверный/истёкший
ключ и uninstall. Не использовать production-пользователей и не публиковать
артефакт без отдельного разрешения.
