# Данные и серверные возможности, необходимые для production-релиза

Этот документ — перечень требований. Серверный проект на этапе 7 не изменялся.

## Обновления

Нужен HTTPS endpoint подписанного manifest с версией, минимально допустимой
версией клиента, URL пакета, размером, SHA-256 и detached signature. Клиент
должен иметь встроенный/закреплённый публичный ключ и проверять подпись и hash до
запуска установщика. Manifest обязан поддерживать каналы, staged rollout и
запрет downgrade. Закрытый signing key не должен находиться на web/API-сервере.

## Тест скорости

Нужны отдельные безопасные endpoints для небольшого latency probe, ограниченного
download payload и upload sink. Должны быть заданы лимиты размера, времени,
частоты, а также защита от использования endpoint как amplification/DoS-сервиса.
Полный тест запускается только вручную.

## Публичные ссылки

До выпуска владелец должен предоставить HTTPS URL:

- поддержки;
- политики конфиденциальности;
- пользовательской документации.

URL нельзя придумывать на стороне клиента. Сейчас соответствующие строки UI
честно помечены как не настроенные.
